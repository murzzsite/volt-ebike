Политика обработки персональных данных

Настоящая политика определяет порядок обработки персональных данных пользователей сайта VOLT (далее — Оператор).

1. Общие положения

Оставляя заявку на сайте, пользователь даёт согласие на обработку своих персональных данных на условиях, изложенных ниже.

2. Состав данных

  • Имя
  • Номер телефона
  • Комментарий к заявке (при заполнении)

3. Цели обработки

Данные используются исключительно для связи с пользователем по вопросам аренды, продажи и сервисного обслуживания электровелосипедов.

4. Хранение и передача данных

Данные передаются оператору через защищённый канал и не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

5. Права пользователя

Пользователь вправе запросить удаление своих данных, направив запрос через контакты, указанные на сайте.

6. Контакты

По вопросам обработки персональных данных: info@volt-ebike.ru, +7 (900) 123-45-67.
